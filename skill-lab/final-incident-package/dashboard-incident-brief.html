Root cause summary

  1. Duplicate order: upstream timeout on ORD-1004 triggered a retry with no idempotency-key check, so both the original and retried write landed.

  4. Stale record: a backfill merge from a previously failed run carried an old record's load_timestamp forward instead of refreshing it.
